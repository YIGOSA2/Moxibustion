# Moxibustion 艾灸设备项目

## 项目概述
本项目包含智能艾灸设备硬件固件与配套微信小程序，两类代码通过不同分支分开管理，独立维护开发。

## 分支说明
- **master 分支**：硬件主固件完整源码，负责设备驱动、温控、通信、设备控制等底层逻辑，用于单片机编译烧录。
- **wechat_project 分支**：配套微信小程序源码，实现设备连接、参数设置、状态监控、运行数据查看等交互功能。

## 分支切换命令
```bash
# 切换至硬件固件分支
git checkout master

# 切换至微信小程序分支
git checkout wechat_project
